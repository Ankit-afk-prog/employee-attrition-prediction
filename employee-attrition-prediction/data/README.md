# Data

`IBM_HR_Analytics_Employee_Attrition.csv` - IBM HR Analytics Employee Attrition & Performance dataset.

| Property | Value |
|---|---|
| Source | Kaggle, user `pavansubhasht`: <https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset> |
| Nature | Fictional (synthetic) data created by IBM data scientists - no real people |
| Size | 1,470 rows x 35 columns, no missing values, no duplicates |
| Target | `Attrition` (Yes = 237, No = 1,233) |
| Licence | Database: ODbL v1.0; Contents: DbCL v1.0 (redistribution allowed with attribution) |
| Delimiter | The copy in this repository is **tab-separated** despite the `.csv` extension. The original Kaggle download is comma-separated. The notebook detects the delimiter automatically, so either version works. |

To use a fresh copy, download it from the Kaggle link above and save it here under the same file name.
Column meanings are listed in `results/data_dictionary.csv`.
